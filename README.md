# Todo-list

Простой планировщик с задачами в пастельных зелёных цветах.Всё работает прямо в браузере без установки или стороннего программного обеспечения. Задачи хранятся в `localStorage`.

https://nurgulibraeva701-rgb.github.io/Todo-list/

## Функции

- Создание задач с датой и временем
- Отмечать задачи как выполненные(задачи будут отмечены)
- Удаление задач с помощью кнопки "..." в панели задач
- Группы: **Сегодня**, **Будущие** и **Просроченные** задачи(не выполненные просроченные задачи)
- Календарь: Переход между месяцами, сегодня выделен, дни с невыполненными задачами отмечены точками ниже; нажатие на дни добавит дату в форму создания
- Боковое меню:
  - **Сегодня** - Задачи на сегодня и будущие
  - **Все задачи** - Все задачи включая прошлые
  - **Календарь** - Прокрутка до календаря
  - **Настройки** - Удаление всех выполненных задач(подтверждающий диалог появляется)
- Время зависящее приветствие
- Адаптивный дизайн(Десктоп, Таблет, Телефон)

## Идеи для разработки

- Редактирование текста задачи
- Фильтрация задач по конкретному дню из календаря
- Темная тема
- JSON импорт/экспорт задач
